Building:

It needs ncurses: http://ftp.gnu.org/pub/gnu/ncurses (http://ftp.gnu.org/pub/gnu/ncurses/ncurses-5.4.tar.gz)

Then everything easy:

```bash
./configure
make
sudo make install
```

(well, I build a rpm with ncurses statically linked to kismet).

Using it:

My Siemens I-GATE 11M PCI uses the orinoco driver (that is an original kernel from www.kernel.org). Of course that doesn't work. But the card is a PrismII based PCMCIA card. So hostap should help (http://hostap.epitest.fi/).
